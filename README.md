### Research

**MSc thesis: policy-constrained next-action prediction for customer-support dialogue.** A DistilRoBERTa model fused with a graph neural network built from the organisation's own procedure. Next-action accuracy rose from 66.2% to 74.3% and procedural breaches fell by 25% on 3,608 held-out turns. It also found that about a quarter of what real agents did was missing from the documented procedure.
